# Performance: dropping the unused search indexes (#109)

Production, `scripts/perf/measure.ts` from Jerusalem, before and after #109
dropped the eight trigram indexes Supabase reported as never used. The
expectation was no change for reads (the planner never used them) and
cheaper writes; reads confirm it.

| Path | Before: TTFB / server (median, ms) | After |
|---|---|---|
| Search `محمد` | 492 / 152 | 450 / 151 |
| Search `الباطنية` | 436 / 152 | 440 / 145 |
| Search `هداسا` | 452 / 153 | 442 / 153 |
| Search `ا` | 439 / 148 | 450 / 149 |
| `/dashboard` | 455 / - | 479 / - |
| `/profile` | 447 / - | 452 / - |

Search's server time is unchanged at about 150 ms; the TTFB differences are
network noise (compare the Connect columns below). Writes (signup, profile
save) no longer update up to eight indexes; they are not measured here.
