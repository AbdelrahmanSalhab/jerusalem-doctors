# Performance: baseline before the October 2026 speed work

Production (`jerusalem-doctors.vercel.app`), measured from Jerusalem with
`scripts/perf/measure.ts`, signed in as an admin, before #100 (search in one
query) and #101 (dashboard cache) were merged. Each request opens a fresh
connection, so Connect and the TLS handshake are included in every TTFB; a
browser reuses its connection after the first request, so a user's later
clicks are faster than these by roughly the connect and TLS share.

The same script, run the same way after the merges, goes in
`2026-10-21-after.md` next to this file.
