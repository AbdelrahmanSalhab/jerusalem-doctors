# Sentry tree-shaking flags (#174)

`compiler.define: { __SENTRY_TRACING__: false, __SENTRY_DEBUG__: false }` in
`next.config.ts`, the same flags `withSentryConfig`'s `bundleSizeOptimizations`
sets under Turbopack. Production build of `main` (Sentry 11.9) against the
same build with the flags, `.next/static/chunks`, gzip -c:

| | Before | After | Change |
|---|---|---|---|
| Chunk holding Sentry (loaded on every page) | 151.5 KB (475 KB raw) | 126.8 KB (402 KB raw) | -24.7 KB (-74 KB raw) |
| All client JS | 381.6 KB | 356.9 KB | -24.7 KB |

Replay and the feedback widget were never in the bundle (no `rrweb`, no
feedback code), so their flags would change nothing and are left out.
