# Performance: after the search filters, filter chips and «جديد هذا الأسبوع»

Production after #111 (filters inside `search_directory()`), #112 (new this
week) and #113 (filter chips), deployed together on 22/10 (a GitHub outage
held the deploys of #112 and #113). Same script and place as before;
compare with the "After" table in `2026-10-21-indexes.md`.

| Path | Before: TTFB / server (median, ms) | After |
|---|---|---|
| Search `محمد` | 450 / 151 | 469 / 128 |
| Search `الباطنية` | 440 / 145 | 460 / 130 |
| Search `هداسا` | 442 / 153 | 453 / 125 |
| Search `ا` | 450 / 149 | 441 / 127 |
| `/dashboard` | 479 / - | 409 / - |

Search's server time did not grow with the four extra filters (if anything
it dropped, likely the redundant name checks removed in #109 plus a quieter
hour); TTFB differences are network. The dashboard's HTML grew from 29 KB to
53 KB: it now carries «جديد هذا الأسبوع» and the places for the filter.
