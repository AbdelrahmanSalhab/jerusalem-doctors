# Security policy

Jerusalem Doctors holds personal data about doctors: names, phone numbers,
licence numbers and workplaces. Please report security problems privately.

## Reporting a vulnerability

Use GitHub's private report form: the **Security** tab of this repository,
then **Report a vulnerability**. Please do not open a public issue.

Include what you found, how to reproduce it, and what you could see or do.
We aim to answer within 72 hours.

## Scope

In scope: jerusalem-doctors.vercel.app, its API routes, sign-in and signup,
and how personal data is stored and shown.

Out of scope: denial of service by volume, social engineering, and problems
in third-party services (Supabase, Vercel, Upstash, SMS4FREE) themselves.

Only the deployed `main` branch is supported.
